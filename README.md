## 📖 项目简介

GXELA 自动学习助手是一款基于 Tampermonkey 的用户脚本，用于辅助个人课程学习流程管理。

脚本提供课程获取、目标学时管理、自动播放、播放队列管理、学习状态保存以及状态同步等功能，减少重复操作，提高学习效率。

> 请仅在本人账号及本人应完成的课程范围内使用，并遵守相关平台规定。

---

# ✨ 功能特性

## 🎯 目标学时管理

- 支持设置必修、选修目标学时。
- 自动保存用户设置。
- 刷新页面后自动恢复配置。
- 根据目标学时计算剩余学习需求。

---

## 📊 学时统计

实时显示：

- 已完成学时。
- 已选未完成课程学时。
- 当前学习进度。
- 剩余目标学时。

支持分类统计不同类型课程学习情况。

---

## 🧩 自动选课

根据目标学时自动：

- 获取课程列表。
- 分析课程信息。
- 计算需要学习的课程。
- 自动生成学习队列。
- 避免重复选择已完成或已选课程。

---

## ▶️ 自动学习

支持：

- 自动进入课程页面。
- 自动播放课程。
- 播放状态检测。
- 异常恢复处理。
- 自动衔接下一课程。
- 刷新页面后继续任务。

---

## 📋 播放队列管理

支持对本地播放队列进行管理：

| 操作 | 说明 |
| --- | --- |
| ▶ 播放 | 立即跳转并播放指定课程 |
| ⭐ 置顶 | 将课程调整到队列前方 |
| ❌ 移出 | 从本地队列移除，不影响课程状态 |
| ⏭ 跳过当前 | 跳过当前播放任务 |
| 🗑 清空队列 | 清除本地播放列表 |
| ↻ 恢复学习 | 从保存位置继续执行 |

> 队列操作仅影响脚本本地管理，不会修改课程记录。

---

## 💾 断点恢复

自动保存：

- 当前课程。
- 播放队列。
- 学习状态。
- 用户配置。
- 运行日志。

关闭页面或刷新后，可以继续之前的学习任务。

---

## 🏫 状态同步

支持课程状态同步处理：

- 自动识别相关课程。
- 执行状态刷新。
- 失败任务自动记录。
- 支持单独重新处理失败项目。

---

## 🔁 异常处理

针对播放过程中的异常情况：

- 自动检测播放状态。
- 尝试恢复播放。
- 记录异常原因。
- 必要时继续后续任务。

---

## 📝 日志管理

支持：

- 实时运行日志。
- 日志查看。
- 日志筛选。
- 日志导出。

方便定位运行问题。

---

# 📦 安装方法

## 1. 安装 Tampermonkey

请先安装浏览器扩展：

https://www.tampermonkey.net/

支持：

- Chrome
- Edge
- Firefox

---

## 2. 安装脚本
## 🌐 CDN 分发

本项目使用 jsDelivr CDN 进行脚本分发，以提升国内用户访问速度和稳定性。

在浏览器打开安装地址：

https://cdn.jsdelivr.net/gh/underdestiny/GXELA@main/GXELA-auto-learn.user.js

浏览器会自动进入 Tampermonkey 安装页面。

确认后点击安装即可。




# 🚀 使用方法

## ① 登录账号

确保浏览器已经登录账号。

---

## ② 打开GXELA任意页面


页面会显示：

GXELA 自动学习

控制面板。

---

## ③ 设置目标学时

填写：

- 学习年份。
- 必修目标学时。
- 选修目标学时。

脚本会自动保存设置。

---

## ④ 配置 clientid

首次运行会自动检测。

如果无法开始：

1. 展开：

clientid 设置

2. 点击：

自动检测

3. 必要时手动填写并保存。

---

## ⑤ 开始学习

点击：

开始自动学习

脚本将自动：

1. 获取当前学习状态。
2. 统计已有学习情况。
3. 生成课程队列。
4. 自动进入课程。
5. 完成播放任务。

---

# 📋 播放队列说明

课程列表支持：

| 功能 | 说明 |
| --- | --- |
| 播放 | 立即开始指定课程 |
| 置顶 | 调整课程播放顺序 |
| 移出 | 删除本地任务 |
| 跳过 | 跳过当前课程 |
| 清空 | 清空当前播放列表 |
| 恢复 | 继续之前学习任务 |

---

# ⚠️ 注意事项

- 使用前请确保账号已登录。
- 请勿分享 Cookie、Token、clientid 等敏感信息。
- 请勿同时开启多个学习任务。
- 涉及实际课程状态修改的操作请谨慎使用。
- 本地队列操作不会影响服务器课程状态。
- 平台接口变化可能导致部分功能失效，需要重新适配。
